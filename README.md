# Task Manager CLI

A command-line task manager for adding, completing, and deleting tasks, with persistence between runs via JSON.

## Features
- Add new tasks
- View all tasks (with completion status)
- Mark tasks as complete
- Delete tasks
- Tasks persist between runs — saved to and loaded from a local JSON file

## Tech Stack
- Python
- OOP (`Task` class, task collection management)
- `json` — persistence
- Custom exceptions for invalid task operations

## Installation
```bash
git clone https://github.com/DenoFury/task-manager-cli.git
cd task-manager-cli
python task_manager.py
```
